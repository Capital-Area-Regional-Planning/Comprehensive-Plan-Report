This R Shiny Web application supports comprehensive plans by generating a report with graphs and tables from the US Census. The report is fully editable and customizable in MS Word. See the live version here: https://capital-area-rpc.shinyapps.io/planning_report_tool_pilot/

The code is easily customizable to run reports for any county in Wisconsin - simply follow the directions in tutorial.Rmd. Adapting the application to a new region will require basic knowledge of the R programming language.
Adapting to counties outside of Wisconsin should be possible with a little extra work, but has not been tested.
